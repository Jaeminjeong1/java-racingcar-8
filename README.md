# java-racingcar-precourse
# 자동차 경주

## 기능 구현 목록

---

- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

### 입력

- [x] "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)"을 출력 후, 자동차 입력받는다.
    - 예외
        - [x] 빈 문자열 입력시 예외

- [ ] "시도할 횟수는 몇 회인가요?"를 출력 후, 시도할 횟수(라운드) 입력 받는다.
    - 예외
        - [ ] 0이하 들어올 경우 예외.
        - [ ] 숫자가 아닌 문자 들어올 시 예외.

### 레이싱카(도메인)
- [ ] 이름 5자 이하
    - 예외
        - [ ] 이름 없어도 예외.
        - [ ] 이름 5자 초과면 예외.
- [ ] 움직인 거리 저장

### 전진 기능

- [ ] 매 횟수마다 0~9인 랜덤값 받는다.
- [ ] 랜덤값이 4이상이면 전진한다. 아니면 정지

### 우승자 집계 기능

- [ ] 가장 많이 전진한 자동차가 우승한다.
- [ ] 우승자는 1명 이상일 수 있다.

### 출력

- [ ] 첫 라운드에 "실행 결과"를 출력 후, 각 라운드마다 전진 현황을 출력한다.
- [ ] "최종 우승자 : ?" 같은 형식으로 우승자 출력한다.
    - [ ] 우승자가 2명 이상일 경우 ","로 구분하여 출력한다.
